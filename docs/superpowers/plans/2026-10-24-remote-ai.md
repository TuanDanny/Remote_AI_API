# RemoteAI: 24/7 Web Dashboard & Local Agent Daemon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây dựng hệ thống Remote AI cá nhân gồm Web Dashboard chạy 24/7 trên Vercel và Local Daemon chạy trên Windows, cho phép điều khiển và giám sát các session coding dùng API Key/Router (Claude/Codex/OpenRouter) từ xa.

**Architecture:** Sử dụng kiến trúc Cloud-Relay. Web Dashboard (Next.js 15) và Local Daemon (Node.js/TypeScript) kết nối hai chiều thông qua Supabase PostgreSQL & Realtime WebSockets. Local Daemon kết nối outbound để thực thi các tool file/terminal trên máy local và stream kết quả về Web.

**Spec:** `docs/superpowers/specs/2026-10-24-remote-ai-design.md`

## Global Constraints

- **Platform Target:** Local Daemon chạy trên Windows 11 (`win32`, PowerShell / CMD / Git Bash). Web Dashboard chạy trên Vercel Edge/Serverless.
- **Node.js Version:** >= 18.x.
- **Zero-Cost Rule:** Hoàn toàn sử dụng gói Free của Vercel và Supabase, không sử dụng bất kỳ dịch vụ trả phí nào ngoại trừ API Key của người dùng.

```typescript
import fs from 'node:fs';
import path from 'node:path';
import spawn from 'cross-spawn';
import * as diff from 'diff';

export interface ToolResult {
  success: boolean;
  content?: string;
  output?: string;
  diff?: string;
  error?: string;
  files?: string[];
}

export class LocalTools {
  private workspaceRoot: string;

  constructor(workspaceRoot: string) {
    this.workspaceRoot = path.resolve(workspaceRoot);
  }

  private resolveSafePath(relPath: string): string {
    const fullPath = path.resolve(this.workspaceRoot, relPath);
    const normalizedRoot = path.normalize(this.workspaceRoot);
    const normalizedPath = path.normalize(fullPath);

    if (!normalizedPath.startsWith(normalizedRoot)) {
      throw new Error(`Access denied: Path is outside workspace (${relPath})`);
    }
    return normalizedPath;
  }

  async readFile(relPath: string): Promise<ToolResult> {
    try {
      const safePath = this.resolveSafePath(relPath);
      if (!fs.existsSync(safePath)) {
        return { success: false, error: `File not found: ${relPath}` };
      }
      const raw = fs.readFileSync(safePath, 'utf8');
      const lines = raw.split('\n');
      const numbered = lines.map((l, i) => `${i + 1}\t${l}`).join('\n');
      return { success: true, content: numbered };
    } catch (err: any) {
      return { success: false, error: err.message };
    }
  }

  async writeFile(relPath: string, content: string): Promise<ToolResult> {
    try {
      const safePath = this.resolveSafePath(relPath);
      const parentDir = path.dirname(safePath);
      if (!fs.existsSync(parentDir)) {
        fs.mkdirSync(parentDir, { recursive: true });
      }
      fs.writeFileSync(safePath, content, 'utf8');
      return { success: true, content: `File written: ${relPath}` };
    } catch (err: any) {
      return { success: false, error: err.message };
    }
  }

  async editFile(relPath: string, oldContent: string, newContent: string): Promise<ToolResult> {
    try {
      const safePath = this.resolveSafePath(relPath);
      if (!fs.existsSync(safePath)) {
        return { success: false, error: `File not found: ${relPath}` };
      }
      const current = fs.readFileSync(safePath, 'utf8');
      if (!current.includes(oldContent)) {
        return { success: false, error: `oldContent not found in ${relPath}` };
      }
      const updated = current.replace(oldContent, newContent);
      fs.writeFileSync(safePath, updated, 'utf8');

      const patch = diff.createPatch(relPath, current, updated, 'before', 'after');
      return { success: true, content: `File updated: ${relPath}`, diff: patch };
    } catch (err: any) {
      return { success: false, error: err.message };
    }
  }

  async listDirectory(relPath: string = '.'): Promise<ToolResult> {
    try {
      const safePath = this.resolveSafePath(relPath);
      const entries = fs.readdirSync(safePath, { withFileTypes: true });
      const files = entries.map(e => e.isDirectory() ? `${e.name}/` : e.name);
      return { success: true, files };
    } catch (err: any) {
      return { success: false, error: err.message };
    }
  }

  async executeCommand(command: string, cwdRel: string = '.'): Promise<ToolResult> {
    return new Promise((resolve) => {
      try {
        const safeCwd = this.resolveSafePath(cwdRel);
        const isWindows = process.platform === 'win32';
        const shell = isWindows ? 'powershell.exe' : '/bin/bash';
        const shellArgs = isWindows ? ['-NoProfile', '-Command', command] : ['-c', command];

        const proc = spawn(shell, shellArgs, {
          cwd: safeCwd,
          env: process.env,
        });

        let output = '';

        proc.stdout?.on('data', (d) => { output += d.toString(); });
        proc.stderr?.on('data', (d) => { output += d.toString(); });

        const timer = setTimeout(() => {
          proc.kill();
          resolve({ success: false, output, error: 'Command timed out after 60s' });
        }, 60000);

        proc.on('close', (code) => {
          clearTimeout(timer);
          resolve({
            success: code === 0,
            output,
            error: code !== 0 ? `Process exited with code ${code}` : undefined
          });
        });

        proc.on('error', (err) => {
          clearTimeout(timer);
          resolve({ success: false, output, error: err.message });
        });
      } catch (err: any) {
        resolve({ success: false, error: err.message });
      }
    });
  }
}
```

```typescript
import { LocalTools } from './tools.js';
import { ToolCall } from '../../types/index.js';

export interface AgentOptions {
  routerBaseUrl: string;
  apiKey: string;
  model: string;
  tools: LocalTools;
}

export class AgentRunner {
  private routerBaseUrl: string;
  private apiKey: string;
  private model: string;
  private tools: LocalTools;

  constructor(opts: AgentOptions) {
    this.routerBaseUrl = opts.routerBaseUrl.replace(/\/+$/, '');
    this.apiKey = opts.apiKey;
    this.model = opts.model;
    this.tools = opts.tools;
  }

  getToolDefinitions() {
    return [
      {
        type: 'function',
        function: {
          name: 'read_file',
          description: 'Read the contents of a file at path',
          parameters: {
            type: 'object',
            properties: { path: { type: 'string', description: 'Relative path to file' } },
            required: ['path']
          }
        }
      },
      {
        type: 'function',
        function: {
          name: 'write_file',
          description: 'Create or overwrite a file at path with content',
          parameters: {
            type: 'object',
            properties: {
              path: { type: 'string', description: 'Relative path to file' },
              content: { type: 'string', description: 'Full content to write' }
            },
            required: ['path', 'content']
          }
        }
      },
      {
        type: 'function',
        function: {
          name: 'edit_file',
          description: 'Replace old_content with new_content in an existing file',
          parameters: {
            type: 'object',
            properties: {
              path: { type: 'string', description: 'Relative path to file' },
              old_content: { type: 'string', description: 'Text to replace' },
              new_content: { type: 'string', description: 'New text' }
            },
            required: ['path', 'old_content', 'new_content']
          }
        }
      },
      {
        type: 'function',
        function: {
          name: 'list_directory',
          description: 'List files and folders in directory',
          parameters: {
            type: 'object',
            properties: { path: { type: 'string', description: 'Relative directory path' } }
          }
        }
      },
      {
        type: 'function',
        function: {
          name: 'execute_command',
          description: 'Execute a shell command on the local machine',
          parameters: {
            type: 'object',
            properties: {
              command: { type: 'string', description: 'Shell command line to execute' }
            },
            required: ['command']
          }
        }
      }
    ];
  }

  async runStep(
    messages: any[],
    onStream: (chunk: string) => void,
    onToolExecute: (toolCall: ToolCall) => Promise<boolean> // returns approval
  ): Promise<{ responseText: string; toolCalls: ToolCall[] }> {
    const url = `${this.routerBaseUrl}/chat/completions`;

    const res = await fetch(url, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${this.apiKey}`
      },
      body: JSON.stringify({
        model: this.model,
        messages,
        tools: this.getToolDefinitions(),
        stream: false
      })
    });

    if (!res.ok) {
      const errText = await res.text();
      throw new Error(`AI Router Error (${res.status}): ${errText}`);
    }

    const data: any = await res.json();
    const choice = data.choices?.[0];
    const message = choice?.message || {};
    const content = message.content || '';
    const rawToolCalls = message.tool_calls || [];

    if (content) {
      onStream(content);
    }

    const toolCalls: ToolCall[] = [];

    for (const tc of rawToolCalls) {
      const name = tc.function?.name;
      let args: any = {};
      try {
        args = JSON.parse(tc.function?.arguments || '{}');
      } catch {
        args = {};
      }

      const toolCall: ToolCall = {
        id: tc.id,
        name,
        args,
        status: 'running'
      };

      let resultText = '';
      if (name === 'read_file') {
        const r = await this.tools.readFile(args.path);
        resultText = r.success ? r.content || '' : `Error: ${r.error}`;
      } else if (name === 'write_file') {
        const r = await this.tools.writeFile(args.path, args.content);
        resultText = r.success ? r.content || '' : `Error: ${r.error}`;
      } else if (name === 'edit_file') {
        const r = await this.tools.editFile(args.path, args.old_content, args.new_content);
        resultText = r.success ? r.content || '' : `Error: ${r.error}`;
        toolCall.diff = r.diff;
      } else if (name === 'list_directory') {
        const r = await this.tools.listDirectory(args.path || '.');
        resultText = r.success ? (r.files || []).join('\n') : `Error: ${r.error}`;
      } else if (name === 'execute_command') {
        toolCall.command = args.command;
        // Check approval if required
        const approved = await onToolExecute(toolCall);
        if (!approved) {
          resultText = 'User rejected this command execution.';
          toolCall.status = 'rejected';
        } else {
          const r = await this.tools.executeCommand(args.command);
          resultText = r.success ? r.output || 'Command completed.' : `Error: ${r.error}\nOutput: ${r.output}`;
          toolCall.status = r.success ? 'completed' : 'failed';
        }
      }

      toolCall.result = resultText;
      if (toolCall.status === 'running') toolCall.status = 'completed';
      toolCalls.push(toolCall);
    }

    return { responseText: content, toolCalls };
  }
}

import { SupabaseClient } from '@supabase/supabase-js';

export class HeartbeatService {
  private client: SupabaseClient;
  private deviceId: string;
  private deviceName: string;
  private workingDirectory: string;
  private timer: NodeJS.Timeout | null = null;

  constructor(client: SupabaseClient, deviceId: string, deviceName: string, workingDirectory: string) {
    this.client = client;
    this.deviceId = deviceId;
    this.deviceName = deviceName;
    this.workingDirectory = workingDirectory;
  }

  async start() {
    // Initial upsert
    await this.ping('online');
    this.timer = setInterval(() => this.ping('online'), 10000);

    const onExit = async () => {
      await this.ping('offline');
      process.exit(0);
    };

    process.on('SIGINT', onExit);
    process.on('SIGTERM', onExit);
  }

  private async ping(status: 'online' | 'offline') {
    try {
      await this.client.from('devices').upsert({
        id: this.deviceId,
        name: this.deviceName,
        status,
        working_directory: this.workingDirectory,
        last_heartbeat: new Date().toISOString()
      });
    } catch (err: any) {
      console.error('[Heartbeat] Ping error:', err.message);
    }
  }

  stop() {
    if (this.timer) clearInterval(this.timer);
    return this.ping('offline');
  }
}

async function handleNewUserMessage(messageRow: any) {
  const sessionId = messageRow.session_id;
  const userContent = messageRow.content;

  console.log(`[Agent] Processing prompt for session ${sessionId}: "${userContent}"`);

  // Update session status to running
  await supabase.from('sessions').update({ status: 'running' }).eq('id', sessionId);

  // Fetch full conversation history
  const { data: allMessages } = await supabase
    .from('messages')
    .select('*')
    .eq('session_id', sessionId)
    .order('created_at', { ascending: true });

  const conversationHistory = (allMessages || []).map((m: any) => ({
    role: m.role,
    content: m.content
  }));

  // Create empty assistant response message in DB
  const { data: assistantMsg } = await supabase
    .from('messages')
    .insert({
      session_id: sessionId,
      role: 'assistant',
      content: '',
      tool_calls: []
    })
    .select()
    .single();

  if (!assistantMsg) {
    console.error('Failed to create assistant message placeholder');
    return;
  }

  let accumulatedContent = '';

  try {
    const result = await agent.runStep(
      conversationHistory,
      async (chunk: string) => {
        accumulatedContent += chunk;
        await supabase
          .from('messages')
          .update({ content: accumulatedContent })
          .eq('id', assistantMsg.id);
      },
      async (toolCall) => {
        // Human-in-the-loop approval: if command execution, can check or auto-approve
        console.log(`[Tool] Running ${toolCall.name} with args:`, toolCall.args);
        return true;
      }
    );

    // Save final tool_calls and content
    await supabase
      .from('messages')
      .update({
        content: result.responseText || accumulatedContent,
        tool_calls: result.toolCalls
      })
      .eq('id', assistantMsg.id);

  } catch (err: any) {
    console.error('[Agent] Execution error:', err.message);
    await supabase.from('messages').insert({
      session_id: sessionId,
      role: 'system',
      content: `Lỗi thực thi từ Agent Daemon: ${err.message}`
    });
  } finally {
    await supabase.from('sessions').update({ status: 'idle' }).eq('id', sessionId);
  }
}

  console.log('🚀 Starting RemoteAI Local Daemon on Windows...');
  console.log(`📂 Workspace Root: ${WORKSPACE_ROOT}`);

  await heartbeat.start();
  console.log('🟢 Heartbeat service active (Online).');

  // Subscribe to new user messages
  supabase
    .channel('messages-channel')
    .on(
      'postgres_changes',
      { event: 'INSERT', schema: 'public', table: 'messages' },
      async (payload) => {
        const newMsg = payload.new;
        if (newMsg.role === 'user') {
          await handleNewUserMessage(newMsg);
        }
      }
    )
    .subscribe();

  console.log('👂 Listening for incoming sessions & prompts from Vercel Web...');

'use client';
import React, { useState, useEffect } from 'react';
import { supabase } from '../lib/supabase';
import { Device, Session, Message } from '../../types';
import { Sidebar } from '../components/Sidebar';
import { ChatFeed } from '../components/ChatFeed';
import { PasscodeGate } from '../components/PasscodeGate';
import { Send } from 'lucide-react';

export default function DashboardPage() {
  const [device, setDevice] = useState<Device | null>(null);
  const [sessions, setSessions] = useState<Session[]>([]);
  const [activeSessionId, setActiveSessionId] = useState<string | null>(null);
  const [messages, setMessages] = useState<Message[]>([]);
  const [prompt, setPrompt] = useState('');
  const [selectedModel, setSelectedModel] = useState('anthropic/claude-3.5-sonnet');

  // Load initial data
  useEffect(() => {
    async function loadData() {
      const { data: dev } = await supabase.from('devices').select('*').limit(1).single();
      if (dev) setDevice(dev);

      const { data: sess } = await supabase.from('sessions').select('*').order('created_at', { ascending: false });
      if (sess && sess.length > 0) {
        setSessions(sess);
        setActiveSessionId(sess[0].id);
      }
    }
    loadData();

    // Subscribe to devices status
    const devSub = supabase
      .channel('device-status')
      .on('postgres_changes', { event: '*', schema: 'public', table: 'devices' }, (payload) => {
        setDevice(payload.new as Device);
      })
      .subscribe();

    return () => {
      supabase.removeChannel(devSub);
    };
  }, []);

  // Load messages for active session & subscribe to realtime
  useEffect(() => {
    if (!activeSessionId) return;

    async function loadMessages() {
      const { data } = await supabase
        .from('messages')
        .select('*')
        .eq('session_id', activeSessionId)
        .order('created_at', { ascending: true });
      if (data) setMessages(data as Message[]);
    }
    loadMessages();

    const msgSub = supabase
      .channel(`messages-${activeSessionId}`)
      .on(
        'postgres_changes',
        { event: '*', schema: 'public', table: 'messages', filter: `session_id=eq.${activeSessionId}` },
        (payload) => {
          if (payload.eventType === 'INSERT') {
            setMessages((prev) => [...prev, payload.new as Message]);
          } else if (payload.eventType === 'UPDATE') {
            setMessages((prev) => prev.map((m) => (m.id === payload.new.id ? (payload.new as Message) : m)));
          }
        }
      )
      .subscribe();

    return () => {
      supabase.removeChannel(msgSub);
    };
  }, [activeSessionId]);

  const handleCreateSession = async () => {
    const { data } = await supabase
      .from('sessions')
      .insert({
        title: 'New Session',
        model: selectedModel,
        status: 'idle'
      })
      .select()
      .single();

    if (data) {
      setSessions([data, ...sessions]);
      setActiveSessionId(data.id);
    }
  };

  const handleDeleteSession = async (id: string) => {
    await supabase.from('sessions').delete().eq('id', id);
    setSessions(sessions.filter((s) => s.id !== id));
    if (activeSessionId === id) {
      const remaining = sessions.filter((s) => s.id !== id);
      setActiveSessionId(remaining[0]?.id || null);
    }
  };

  const handleSendMessage = async (e: React.FormEvent) => {
    e.preventDefault();
    if (!prompt.trim() || !activeSessionId) return;

    const userText = prompt.trim();
    setPrompt('');

    await supabase.from('messages').insert({
      session_id: activeSessionId,
      role: 'user',
      content: userText
    });
  };

  const activeSession = sessions.find((s) => s.id === activeSessionId);

  return (
    <PasscodeGate>
      <div className="flex h-screen w-full bg-[#0d1117] overflow-hidden">
        <Sidebar
          device={device}
          sessions={sessions}
          activeSessionId={activeSessionId}
          onSelectSession={setActiveSessionId}
          onCreateSession={handleCreateSession}
          onDeleteSession={handleDeleteSession}
        />

        <main className="flex-1 flex flex-col h-screen">
          {/* Header */}
          <header className="h-14 border-b border-[#30363d] bg-[#161b22] px-6 flex items-center justify-between">
            <div className="font-semibold text-sm text-white truncate">
              {activeSession?.title || 'Chọn một phiên làm việc'}
            </div>
            <select
              value={selectedModel}
              onChange={(e) => setSelectedModel(e.target.value)}
              className="bg-[#0d1117] border border-[#30363d] rounded-lg px-2.5 py-1 text-xs text-gray-300 outline-none focus:border-[#58a6ff]"
            >
              <option value="anthropic/claude-3.5-sonnet">Claude 3.5 Sonnet</option>
              <option value="openai/gpt-4o">GPT-4o</option>
              <option value="deepseek/deepseek-chat">DeepSeek V3</option>
            </select>
          </header>

          {/* Chat Feed */}
          <ChatFeed messages={messages} sessionStatus={activeSession?.status || 'idle'} />

          {/* Input Box */}
          <footer className="p-4 border-t border-[#30363d] bg-[#161b22]">
            <form onSubmit={handleSendMessage} className="max-w-4xl mx-auto flex gap-2">
              <input
                type="text"
                value={prompt}

# RemoteAI: 24/7 Web Dashboard & Local Agent Daemon

Hệ thống điều khiển AI Agent từ xa chạy 24/7 trên Vercel dành cho người dùng dùng API Key / API Router (Claude, Codex, OpenRouter).

## 1. Cài đặt Database (Supabase Free)
1. Tạo một dự án miễn phí tại [supabase.com](https://supabase.com).
2. Vào **SQL Editor**, mở file `supabase/schema.sql` và nhấn **Run** để khởi tạo các bảng.
3. Lấy `Project URL` và `anon/public key` từ mục **Settings > API**.

## 2. Triển khai Web lên Vercel (24/7)
1. Đẩy code lên GitHub repository của bạn.
2. Đăng nhập Vercel và bấm **Add New > Project**, chọn repository này.
3. Chọn Root Directory là `apps/web`.
4. Thêm các biến môi trường (Environment Variables):
   - `NEXT_PUBLIC_SUPABASE_URL`: URL Supabase của bạn.
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`: Anon Key của Supabase.
   - `NEXT_PUBLIC_DASHBOARD_PIN`: Mã PIN bảo vệ (ví dụ `123456`).
5. Bấm **Deploy**. Bạn sẽ có link web dạng `https://remote-ai-xxx.vercel.app`.

## 3. Chạy Local Daemon trên máy tính Windows
1. Vào thư mục `daemon`, copy file `.env.example` thành `.env`:
   ```bash
   cp daemon/.env.example daemon/.env
   ```
2. Điền thông tin vào `daemon/.env`:
   - `SUPABASE_URL` & `SUPABASE_KEY`
   - `AI_ROUTER_BASE_URL` & `AI_ROUTER_API_KEY` (OpenRouter, Claude API, OneAPI...)
   - `ALLOWED_WORKSPACE_ROOT`: Thư mục bạn muốn cấp quyền cho Agent (ví dụ `D:\Project`).
3. Chạy script `daemon/start.bat` hoặc lệnh:
   ```bash
   cd daemon && npm install && npm run dev
   ```
4. Khi Daemon báo `🟢 Heartbeat service active (Online)`, bạn có thể mở web trên điện thoại từ bất cứ đâu để điều khiển máy tính của mình!
```
